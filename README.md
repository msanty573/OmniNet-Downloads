# MJSNet downloads — the old address

**MJSNet** was called **OmniNet** until November 2026. This repository exists only to keep the old address
working for copies installed before the rename: their update files and their Linux package repositories
(apt and dnf) are still served from here.

- **Get MJSNet:** https://mjsapps.net/mjsnet/
- **Downloads:** https://github.com/msanty573/MJSNet-Downloads/releases/tag/latest
- **Linux package repositories** (new installs use these): https://msanty573.github.io/MJSNet-Downloads/

Nothing here needs your attention. Copies of MJSNet and OmniNet keep updating by themselves.
